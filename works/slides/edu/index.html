Отчёт по возвратам за октябрь

Посчитайте долю возвратов по складам, найдите три склада с самым высоким показателем и предложите гипотезу для руководителя склада.

  • Выгрузка заказов за октябрь
  • Запрос с долей возвратов
  • Вывод для руководителя склада
SELECT warehouse,
  count(*) FILTER (WHERE status = 'return') AS returns,
  round(100.0 * count(*) FILTER (WHERE status = 'return')
        / NULLIF(count(*), 0), 1) AS rate
FROM orders
WHERE created_at >= '2026-10-01'
  AND created_at < '2026-11-01'
GROUP BY warehouse
ORDER BY rate DESC
LIMIT 3;
