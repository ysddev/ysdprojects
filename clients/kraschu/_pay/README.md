# Оплата «Крашу сама» (ЮKassa)

Функция `index.js` — для Yandex Cloud Functions, среда Node.js 18, точка входа `index.handler`, публичный вызов.
Ключи в код не вписываются — только в «Переменные окружения» функции:
`YK_SHOP_ID`, `YK_SECRET`, `TOKEN_SECRET`, `SITE`, `SEND_RECEIPT`.

После создания функции её адрес вписать в `PAY_API` в `pay.html` и `lesson.html` — сайт переключится с макета на настоящую оплату.
В ЮKassa: «Интеграция» → «HTTP-уведомления» не обязательны (оплата проверяется по возвращению на сайт).
