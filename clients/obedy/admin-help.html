Инструкция администратора

Всё, что нужно для ежедневной работы. Время на сайте — томское.

1. Первый день

  1. Настройки: время окончания приёма, дни доставки, почта для заказов. Нажмите «Отправить тестовое письмо» и проверьте, что оно пришло (загляните в «Спам»).
  2. Меню: добавьте обеды с фото, составом и ценой.
  3. Компании: добавьте партнёров с адресом доставки.
  4. Сотрудники: создайте учётные записи по одной или «Загрузить списком».

2. Как выдать доступ сотруднику

  • После создания сайт один раз покажет логин и временный пароль. Отправьте их сотруднику или нажмите «Скачать списком» и перешлите файл офис-менеджеру компании.
  • При первом входе сотрудник сам придумает пароль и даст согласие на обработку данных.
  • Забыл пароль — откройте сотрудника → «Выдать новый пароль».
  • Уволился — «Отключить доступ». Заказы останутся в отчётах.
  • Компания перестала сотрудничать — отключите компанию: войти не сможет никто из её сотрудников.

3. Каждый день

  • Каждый заказ приходит письмом. После окончания приёма — одна сводка: сколько каких обедов и куда везти.
  • В «Заказах» то же самое видно на экране: блоки «На кухню» и «Доставка».
  • Статусы: Новый — сотрудник ещё может отменить (пока идёт приём). Принят — взят в работу, отменить сам уже не может. Выполнен — доставлен. Кнопка «Принять все новые» меняет статус разом.

4. Меню

  • «Скрыть» убирает обед из меню, не удаляя. Удобно на время.
  • Для меню по дням недели отметьте у обеда только нужные дни.
  • Стрелки ↑↓ меняют порядок карточек.
  • Изменение цены не трогает уже оформленные заказы: в них остаётся цена на момент заказа.

5. Отчёт

  • Отчёт → период → компания (или все) → «Скачать .xlsx».
  • Для счёта компании выберите её и прошлый месяц: лист «По компаниям» даст итог.

6. Безопасность

  • Меню, цены и фото видны только после входа, поисковики сайт не индексируют.
  • После 5 неверных паролей вход по этому логину блокируется на 15 минут.
  • Пароли не видит никто, даже администратор: можно только выдать новый.
