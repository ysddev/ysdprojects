Инструкция администратора

Всё для ежедневной работы. Время на сайте — томское.

1. Первый запуск

  1. Настройки: время приёма обедов и завтраков, почта для заказов. Нажмите «Отправить тестовое письмо» (загляните в «Спам»).
  2. Меню: позиции по разделам — домашние, лёгкие, бизнес-обеды, завтраки. Для домашнего обеда понедельника отметьте только «пн».
  3. Компании: добавьте компанию и все её площадки — адреса, куда возить.
  4. Сотрудники → «Загрузить ведомость»: файл Excel с ФИО и табельными номерами.

2. Доступ сотрудникам

  • Логин — табельный номер. Первый пароль — табельный номер или случайный (выбираете при загрузке). При первом входе сотрудник задаёт свой пароль и даёт согласие на обработку данных.
  • После загрузки скачайте список логинов и паролей и передайте компании.
  • Забыл пароль — откройте сотрудника → «Выдать новый пароль».
  • Уволился — «Отключить доступ». Заказы останутся в отчётах.
  • Повторная загрузка ведомости не создаёт дублей: сотрудники с тем же табельным просто обновятся.

3. Каждый день

  • Вечером после окончания приёма завтраков и утром после окончания приёма обедов приходит сводка: сколько каких позиций и на какую площадку.
  • То же на экране «Заказы»: блоки «На кухню» и «Доставка по площадкам».
  • Статусы: Новый — сотрудник ещё может отменить. Принят — взят в работу, отменить уже нельзя. Выполнен — доставлен.

4. Отчёты для компаний

  • Отчёты → компания → «Сегодня» → «Скачать .xlsx» — ежедневный отчёт для компании.
  • В конце месяца: компания → «Прошлый месяц». Лист «Сверка по сотрудникам» — табельные номера и суммы для сверки с ведомостью.

5. Безопасность

  • Меню, цены и фото видны только после входа, поисковики сайт не индексируют.
  • После 5 неверных паролей вход по логину блокируется на 15 минут.
  • Пароли не видит никто, даже администратор: можно только выдать новый.
